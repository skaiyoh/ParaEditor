## Decisions

- Centralize product projection and rendering in publication so driver products and document changes reach the renderer, alongside style/Fry edits.
  Remove the earlier separate edit/import draw calls to avoid drawing twice.
- Preserve import refusal on renderer failure: the import publication uses `refuseOnRenderError`, leaving the previous scene owned and closing the failed candidate.
  Other publication failures surface a status message while retaining the changed document, preserving D2a's edit behavior and preventing renderer exceptions from disrupting driver callbacks.
- Retain `renderPng(renderer)` for both download methods; it delegates to `renderer.exportStill()`.
- Keep D3's analysis status presentation and dev-only last timing, rather than reverting the status line for the older scenario assertions.
